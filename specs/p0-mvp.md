# P0 — 最小可用 MVP（进-销-存核心闭环）

> **目标**：跑通商品 → 进货 → 销货 → 库存的完整业务流程，可实际用于日常开单。
> **前置条件**：无
> **估时**：2-3 周

---

## 交付清单

### A1 — 商品分类与档案

**分类树**
- 预置 7 个一级分类：种子 / 农药 / 化肥 / 农膜 / 饲料 / 农具 / 其他
- 支持二级分类（如 农药 → 杀虫剂 / 杀菌剂 / 除草剂）
- 页面：左侧分类树（可折叠），右侧商品列表

**商品档案字段**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 商品编码 | String | 自动生成 | 格式: SP-YYYYMMDD-XXX |
| 通用名 | String(100) | ✅ | 如"吡虫啉" |
| 商品名 | String(100) | — | 如"大功臣" |
| 条码 | String(50) | — | 扫码枪识别用 |
| 规格 | String(50) | — | 如"500ml×20瓶" |
| 剂型 | String(50) | — | 乳油/悬浮剂/可湿性粉剂等 |
| 含量 | String(50) | — | 如"10%" |
| 毒性 | Enum | — | 低毒/中等毒/高毒/剧毒 |
| 登记证号 | String(50) | — | 农药登记证 |
| 生产许可证号 | String(50) | — | — |
| 生产企业 | String(100) | — | — |
| 品牌 | String(50) | — | — |
| 基本单位 | String(10) | ✅ | 瓶/袋/箱/桶 |
| 拆零单位 | String(10) | — | g/ml |
| 换算率 | Float | — | 1瓶=500ml → 填 500 |
| 参考进价 | Float | — | — |
| 零售价 | Float | — | 默认销售单价 |
| 批发价 | Float | — | — |
| 会员价 | Float | — | — |
| 限制农药 | Boolean | 自动 | 毒性=高毒/剧毒 → 自动勾选 |
| 停用 | Boolean | — | 默认启用 |

**页面功能**
- 列表页：搜索（名称模糊 + 条码精确）、分页 20 条、按分类筛选
- 表单页：新增/编辑共用同一表单、分类下拉选择、换算率在选了拆零单位后提示填写
- 操作：启用/停用切换（停用的商品不出现在销售搜索中）

### B1 — 进货入库单

**流程**
1. 选择供应商（下拉搜索）
2. 添加商品行：搜索商品 → 选择 → 填数量 + 单价 → 自动计算金额
3. 可添加多行（一单多品）
4. 底部合计金额自动计算
5. 保存 → 库存实时增加

**字段 (进货单头)**

| 字段 | 说明 |
|------|------|
| 单号 | PO-YYYYMMDD-XXX，自动生成 |
| 供应商 | 外键 supplier_id |
| 日期 | 默认当天，可改 |
| 合计金额 | 自动计算 |
| 备注 | Text |

**字段 (进货明细)**

| 字段 | 说明 |
|------|------|
| 商品 | 外键 product_id |
| 数量 | Float（以基本单位计） |
| 单价 | Float |
| 金额 | = 数量 × 单价 |
| 批号 | P0 阶段可为空（P1 必填） |
| 生产日期 | P0 阶段可为空 |
| 有效期至 | P0 阶段可为空 |

**库存更新逻辑**
- 保存进货单时触发
- 查 `inventory` 表该商品是否存在：
  - 存在：`quantity += 进货数量`, `available_quantity += 进货数量`
  - 不存在：INSERT 新行
- 事务保证：进货单 + 库存更新在同一事务内

### C1 — 零售开单

**流程**
1. 进入开单页面
2. 搜索/扫描商品 → 加入购物车
3. 购物车内可修改数量（拆零模式录入时自动换算）
4. 可删除购物车行
5. 选择支付方式 → 确认开单
6. 开单完成后清空购物车

**搜索功能**
- 输入框支持：条码精确匹配、商品名称模糊匹配
- 实时建议下拉（AJAX 请求 + 防抖 300ms）
- 显示：商品名 + 规格 + 零售价 + 库存可用量

**拆零销售**
- 商品有拆零单位时，购物车行显示两个输入框：
  - 拆零量（如"300"ml）+ 基本量（自动计算 = 300/500 = 0.6）
  - 用户只需填一个，另一个联动
- 库存扣减始终以基本单位计量

**购物车（客户端存储）**
```javascript
// sessionStorage 存储
const cart = [
    { productId: 1, name: "吡虫啉", quantity: 2, unitPrice: 15.00,
      splitMode: false, splitQty: null, splitTotal: null },
    { productId: 5, name: "草甘膦", quantity: 0.6, unitPrice: 20.00,
      splitMode: true, splitQty: 300, splitTotal: "300ml" }
];
```

**支付方式**
- 现金、微信、支付宝、挂账（赊销）
- 选择挂账时 → 弹出客户选择器 → 必选客户

**销售单号**：SO-YYYYMMDD-XXX

### C2 — 赊销挂账

- 开单时支付方式选"挂账" → 必须选择客户
- 保存后自动记入 `ar_transaction`：
  - type = "debit"（赊销）
  - amount = 销售单总额
  - 关联 sale_order_id
- P0 阶段不做信用额度控制（P2 再补）
