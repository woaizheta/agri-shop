**还款录入**
- 选择客户 → 填还款金额 → 确认
- 后端 FIFO 核销逻辑：

```python
def fifo_settle(db, customer_id, payment_amount):
    """FIFO核销：自动冲销最早的未结清挂账单"""
    unpaid_orders = db.query(SaleOrder).filter(
        SaleOrder.customer_id == customer_id,
        SaleOrder.payment_method == "credit",
        SaleOrder.is_paid == False,
        SaleOrder.is_reversed == False
    ).order_by(SaleOrder.order_date.asc()).all()
    
    remaining = payment_amount
    for order in unpaid_orders:
        if remaining <= 0:
            break
        unpaid = order.total_amount - order.paid_amount
        settle = min(remaining, unpaid)
        order.paid_amount += settle
        if order.paid_amount >= order.total_amount:
            order.is_paid = True
        # 生成 ARTransaction(type="credit")
        db.add(ARTransaction(
            customer_id=customer_id,
            sale_order_id=order.id,
            type="credit",
            amount=settle,
            note=f"还款核销 {order.order_no}"
        ))
        remaining -= settle
    db.commit()
```

### E4 — 利润概览

**核心公式**
```
销售毛利 = Σ(sale_item.quantity × (sale_item.unit_price - 当时的移动加权平均成本))
净利润 = 销售毛利 - 当期费用总额
```

**数据来源**
- 销售额：来自 `sale_order` + `sale_item`
- 成本：必须从销售那一刻的 `inventory.cost_price` 快照取值。P2 方案：
  - 在 `sale_item` 表新增 `cost_price_at_sale` 字段
  - 开单时把当时的 `inventory.cost_price` 写入该字段
  - 历史数据（P0/P1 产生的）用 `inventory.cost_price` 近似

**页面**
- 顶部：毛利 / 费用 / 净利润 三个大卡片
- 折线图：按天/周/月切换显示毛利-费用-净利润三条线
- 时间范围选择
